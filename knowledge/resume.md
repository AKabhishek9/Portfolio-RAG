## Projects

### 1. Money Ledger | WebApp
*Next.js, TypeScript, Firebase, Dexie.js*  
- Money Ledger is an offline-first Next.js TypeScript Firebase Dexie.js accounting and expense-tracking web app. Users keep their own ledgers, track transactions and have balances calculated automatically, with the data still available even when they are offline.  
- Data is saved locally with IndexedDB using Dexie.js and synced to Firebase when connectivity is restored. Other features include PDF and CSV export, real-time multi-device sync, and a mobile-first responsive interface designed for daily financial record keeping.  

### 2. ArkFace | Real-Time Face Recognition System | .exe
*Python, OpenCV, MediaPipe, ArkFace*  
- This project is a real-time face recognition system using Python, OpenCV, MediaPipe and ArkFace. The system takes live webcam input, detects multiple faces, extracts facial landmarks and performs real-time identity matching.  
- The application managed to reach about 90 percent recognition accuracy by utilizing MediaPipe’s facial landmark detection and ArcFace-based face embeddings. The model was also tested in challenging situations such as low-light conditions and partial face occlusions, to enhance its reliability and performance for real-world practical applications.  

### 3. QuizAI | AI-Powered Adaptive Quiz Platform | WebApp
*Next.js, Node.js, MongoDB, Firebase Authentication, Groq API*  
- QuizAI is a full-stack adaptive learning platform that creates personalized quizzes with artificial intelligence. The platform is built using Next.js, Node.js, MongoDB, Firebase Authentication and Groq API.  
- Generates questions dynamically based on the user’s performance and it does not repeat the questions which have been attempted before.  
- Users get a tailored learning experience with adaptive question selection and progress tracking. The app boasts secure authentication, efficient database management, and cloud deployment using Vercel and Render, offering a scalable and responsive user experience.
