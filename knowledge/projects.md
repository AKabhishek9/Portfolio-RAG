## Comparative Matrix

### 1. [Money Ledger](file:///c:/Users/abhis/Desktop/Project/Portfolio/knowledge/projects/money-ledger.md)
- **Problem Solved**: Enables users to keep accurate financial ledgers even without an internet connection.
- **Key Technical Innovation**: Offline-first client-side data persistence via IndexedDB (Dexie.js) with background synchronization to Firebase when online.
- **Key Features**: Auto-calculating balances, multi-ledger tracking, real-time multi-device sync, PDF/CSV exports, mobile-first design.

### 2. [ArkFace](file:///c:/Users/abhis/Desktop/Project/Portfolio/knowledge/projects/arkface.md)
- **Problem Solved**: Real-time biometric identity verification under real-world challenging conditions.
- **Key Technical Innovation**: Hybrid vision pipeline combining MediaPipe facial landmark detection with ArcFace deep embedding representations.
- **Key Features**: Live webcam stream processing, multi-face detection, robust performance under low light and partial occlusions, ~90% recognition accuracy.

### 3. [QuizAI](file:///c:/Users/abhis/Desktop/Project/Portfolio/knowledge/projects/quizai.md)
- **Problem Solved**: Lack of personalized, adaptive assessment in traditional standardized testing.
- **Key Technical Innovation**: Real-time LLM question generation via Groq API paired with an adaptive algorithm that factors in historical attempts to prevent question repetition.
- **Key Features**: Dynamic difficulty adaptation, Firebase Authentication, MongoDB document storage, multi-cloud hosting on Vercel and Render.
